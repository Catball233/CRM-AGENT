CRM-AGENT 云端测试包

本说明与 crm-agent-cloud-test-source.zip 配套。该压缩包包含应用源码、迁移、虚构知识样例及 C06 v1 本地报价规则；不包含 API Key、.env、SQLite 运行库、会话记录、日志、node_modules 或构建缓存。

本项目不是单一静态 HTML：网页、NestJS API、SQLite 报价规则和百炼密钥共同构成测试链路。
此 HTML 是云测部署说明；实际访问入口是部署后的 Next.js 网页（默认端口 3000）。

服务器依赖（Ubuntu 22.04 / 24.04）

sudo apt-get update
sudo apt-get install -y curl ca-certificates unzip git build-essential

# 安装 Node.js 24 LTS（也可使用企业已批准的 Node 24 发行版）
curl -fsSL https://deb.nodesource.com/setup_24.x | sudo -E bash -
sudo apt-get install -y nodejs
corepack enable
corepack prepare pnpm@11.9.0 --activate

node --version
pnpm --version

若使用 Docker 部署，服务器仅需 Docker Engine 与 Docker Compose v2；但本包当前提供的是 Node.js 直接部署步骤。

解压与配置

unzip crm-agent-cloud-test-source.zip -d crm-agent-cloud-test
cd crm-agent-cloud-test
cp .env.example .env
chmod 600 .env

仅在服务器上的 .env 填入以下真实值，绝不回传、提交或上传该文件：

DASHSCOPE_API_KEY=...
BAILIAN_WORKSPACE_ID=...
BAILIAN_KNOWLEDGE_BASE_ID=...
BAILIAN_KNOWLEDGE_SEARCH_AGENT_ID=...
BAILIAN_MODEL_ID=qwen3.7-plus
DATABASE_URL=file:./data/cloud-test.sqlite

安装、建库、启动

pnpm install --frozen-lockfile
pnpm db:rebuild
pnpm build

# 终端 1：仅监听本机，供网页反向代理调用
pnpm --filter @crm-agent/api start

# 终端 2：对外网页服务
CRM_AGENT_API_ORIGIN=http://127.0.0.1:3001 \
  pnpm --filter @crm-agent/web start -- --hostname 0.0.0.0

访问 http://服务器IP:3000。生产测试应使用 HTTPS 反向代理，并且只开放 80/443；不要对公网开放 3001。

云端验收

  1. 打开网页并创建测试会话。
  2. 公共问答：环保材料和施工工期需要注意什么？
  3. 本地报价：上海 90㎡旧房装修，全屋，材料档位演示标准，设计师档位演示标准，给我报价；预期为 96,000 元。
  4. 混合意图：环保材料怎么选，顺便 90㎡旧房全屋多少钱？；预期转人工路径。
仅用于演示与虚构数据测试。不得输入客户个人信息、真实报价、生产业务规则或任何密钥；云测结束后删除服务器上的 .env 与 data/cloud-test.sqlite。
