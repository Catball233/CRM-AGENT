# Quote rule samples

Store versioned fictional quote rules and manually reconciled expected totals here.

`c04-fictional-valid-bundle.json` is a deliberately fictional C-04 import example. It contains no
real customer data, supplier identity, negotiated wholesale price, or production commercial rule.
Its matching evidence, guardrail, supplier snapshot, promotion, and reconciliation fixtures are
constructed by the integration test so that every activation decision remains deterministic and
auditable.
